A Perplexity expandiu sua ferramenta de Computador Pessoal para o Windows, permitindo que os computadores que executam o sistema operacional mais popular do mundo sejam usados como um sistema de IA executado localmente. Como a versão para Mac que o Perplexity lançou em abril, o Personal Computer for Windows funciona como um "trabalhador digital de uso geral" que pode acessar arquivos e aplicativos locais para executar ações em seu nome, como criar documentos Atualização de planilhas

Este lançamento baseia-se nas integrações de Computador Pessoal que a Perplexity lançou para os aplicativos de espaço de trabalho 365 da Microsoft e o software de reuniões virtuais do Teams em maio. O Personal Computer for Windows visa preencher a lacuna restante operando diretamente dentro do ambiente Windows, disse a Perplexity em seu comunicado de imprensa, observando que o trabalho corporativo para o qual a ferramenta agentic é projetada normalmente ocorre localmente no Dispositivos Windows "fora do alcance da IA".

"Agora os usuários da Microsoft podem pedir ao computador para trabalhar em seus arquivos locais, no Microsoft Office 365 e na Web em um só lugar", disse Perplexity. "Ele é construído para a maneira muitas vezes confusa como o trabalho corporativo é feito em máquinas locais."

O Personal Computer for Windows está sendo lançado para pagar usuários Max e Enterprise Max hoje, em níveis de assinatura que começam a partir de $ 200 por mês. A Perplexity diz que a ferramenta não treina em dados da empresa e que o Personal Computer for Windows sempre notifica os usuários antes de executar ações confidenciais, como enviar e-mails e excluir arquivos.
