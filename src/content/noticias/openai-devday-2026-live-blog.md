Estou no OpenAI DevDay hoje, em Fort Mason, São Francisco. Da mesma forma que no ano passado, estarei ao vivo blogando a palestra e algumas outras notas durante o dia.

Este ano, criei um sistema para adicionar fotos mais facilmente ao meu blog ao vivo. Eu pretendia fazer isso usando o Codex Cloud (eu o construí no meu telefone a caminho do local), mas tive problemas com isso e mudei para o Claude Code para web.

10:01 Sam Altman está no palco, nos dando as boas-vindas ao DevDay. Ele promete "nosso melhor DevDay até agora".

10:02 Mostrando recursos que eles enviaram que as pessoas pediram. O Codex no Linux e o Codex no seu telefone receberam alguns aplausos.

10:03 Hoje, um produto para se sentir como uma "maneira totalmente nova de trabalhar com IA". Meu palpite é que é um agente pessoal semelhante ao Muse...

10:05 Parece muito com uma musa. Você escolhe o nome dele e ele é representado por um avatar fofo parecido com uma bolha. (O avatar da Minha Musa é um pelicano.)

10:06 Este vídeo de demonstração inclui muitas interações de voz, presumivelmente usando o GPT-Live ou uma nova geração dessa tecnologia.

10:08 Um caso de uso muito ambicioso, migrando uma API. Estou surpreso que eles tenham optado por um exemplo tão pesado em código tão cedo, acho que este é um público de desenvolvedores.
