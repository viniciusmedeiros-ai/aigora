Desde que alguém se lembra, o GitHub tem sido o host de código de fato preferido pela maioria dos desenvolvedores. No entanto, nos últimos tempos, a plataforma tem lutado com interrupções e degradação de desempenho amplamente divulgadas e, à medida que cai a bola, o Cursor está esperando para pegá-la.

A startup de IA, que agora faz parte oficialmente da SpaceX , lançou o Origin esta semana — uma nova plataforma de hospedagem de código projetada para fazer todas as coisas para as quais os desenvolvedores normalmente usam o GitHub: trabalhar colaborativamente em bases de código, navegar e editá-las, lidar com solicitações de pull (edições feitas por outras pessoas pedindo para serem adicionadas à base de código principal) e armazená-las em repositórios.

Este parece ser um próximo passo natural para a Cursor, cujo foco principal até este ponto tem sido a venda de serviços automatizados de desenvolvimento web através do seu AI Code Editor . Cursor também disse que os recursos "nativos do agente" estarão disponíveis em breve para o Origin, embora ainda não tenha compartilhado muitos detalhes. A empresa também diz que está construindo um "ecossistema de aplicativos" mais amplo para apoiar esforços de codificação mais amplos dentro Origem

Curiosamente, o uso do Origin não exige que o usuário pare de usar o GitHub. De fato, o Origin foi projetado para permitir que os desenvolvedores trabalhem ao lado do GitHub e passem código de um lado para o outro entre os dois de maneira interoperável.

"Seus repositórios do GitHub podem ficar ao lado dos que o Cursor hospeda", diz o Cursor em seu blog . “Conecte o GitHub ao Cursor, escolha sua organização e você verá os repositórios que pode sincronizar. Selecione um e o Cursor o puxa para dentro.”

O lançamento do Origin coincide com a frustração contínua com uma queda percebida nos serviços do GitHub. De fato, no mesmo dia em que a Cursor lançou sua nova plataforma, o GitHub sofreu uma interrupção mundial bastante longa. Por mais de seis horas, as funções do local foram supostamente degradadas, com uma taxa de erro de quase 20% em todo o mundo.

Também não é a primeira vez que isso acontece. No início deste ano, após uma série de interrupções, o GitHub anunciou novas ações para saciar os codificadores insatisfeitos, à medida que seus problemas de disponibilidade pareciam aumentar. De forma mais ampla, a plataforma sofreu 257 interrupções no ano passado, segundo uma análise recente da LeadDev. Tais problemas persistentes levaram a "um êxodo visível de usuários de alto perfil", escreve LeadDev repórter Charles Humble.

Ainda assim, se o Cursor quiser competir com o GitHub, ele terá seu trabalho cortado para ele. De acordo com as próprias métricas do GitHub, cerca de 180 milhões de desenvolvedores usam sua plataforma em outubro passado. A plataforma, que foi fundada em 2007 e adquirida pela Microsoft em 2012, continua a ser o maior host de código-fonte do mundo.
