A alternativa de código aberto do Windows, ReactOS, atingiu um marco importante: o sistema operacional agora pode ser instalado diretamente em uma partição de unidade do Sistema de Arquivos NT. Conforme relatado pela Phoronix , a mudança para o NTFS elimina um obstáculo de longa data para o projeto e o aproxima de finalmente chegar ao beta.

Antes deste último anúncio, o ReactOS exigia que os usuários mantivessem uma partição FAT32 para instalações. Um sistema de arquivos proprietário desenvolvido pela Microsoft, o NTFS pode rastrear suas raízes através da linhagem da família Windows NT a partir de 1993 com o Windows NT 3.1. A variante introduzida com o Windows XP em 2001 continua sendo o padrão usado pela maioria dos sistemas Windows atualmente. Com o objetivo declarado do ReactOS de alcançar compatibilidade binária com o Windows Server 2003, estar confinado a partições FAT32 era uma barreira prática para limpar o caminho para reproduzir o ambiente Windows.

No entanto, os usuários que querem pular do trem do Windows ainda não deveriam estar pegando suas malas. O ReactOS escreveu que o novo driver ainda “carece de armazenamento em cache (o que causa desempenho inferior), registro em diário e suporte de segurança." Então, enquanto o novo motorista estiver aqui, mesmo o mais intrépido dos inventores de sistemas operacionais deve agir com cuidado. A equipe do ReactOS alertou em seu anúncio no X que ainda existem “potencialmente insetos não descobertos."
