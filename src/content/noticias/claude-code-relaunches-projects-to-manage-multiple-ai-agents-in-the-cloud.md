O recurso de projetos renovados no Claude Code permite que os usuários executem vários agentes sob o mesmo teto, com uma memória compartilhada, objetivos e biblioteca de arquivos e artefatos. Semelhante ao Grok Bot e outras ferramentas que gerenciam grupos de agentes de IA, cada projeto tem "threads" executando tarefas diferentes em paralelo, com um "coordenador" direcionando tudo:

Sob o capô, cada thread é uma sessão na nuvem do Claude Code trabalhando em sua própria ramificação e cópia do repositório. O coordenador mantém o trabalho organizado, mas se quaisquer threads funcionarem no mesmo código, a sobreposição é resolvida como um conflito de mesclagem, assim como qualquer outro PR. Cada thread pode dividir ainda mais seu trabalho delegado em partes usando subagentes, loops e fluxos de trabalho quando necessário para que tarefas grandes sejam concluídas mais rápido.

Os usuários podem interagir com cada tópico individualmente ou monitorar e atualizar as coisas através do chat principal do projeto. No lançamento, os threads são executados na nuvem, mas a Anthropic diz que o suporte para ferramentas e códigos locais está chegando "muito em breve.” O recurso de projetos atualizados está disponível em versão beta a partir de hoje para “assinantes selecionados Claude Pro e Max”, com acesso expandido para todos os usuários Pro, Max, Team e Enterprise mais tarde, assim como o Cowork e as conversas regulares de Claude.
