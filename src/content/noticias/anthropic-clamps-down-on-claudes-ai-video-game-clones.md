A Anthropic atualizou o prompt do sistema do Claude Code para evitar que a ferramenta de IA seja usada para recriar videogames existentes, conforme relatado pela Tom's Hardware . Atualmente, os jogos retrô estão sendo invadidos por descompilações, recompilações e portas feitas por IA, mas, embora o Anthropic ainda permita que as pessoas usem o Claude Code para criar jogos, ele não quer que as pessoas o usem para clones diretos.

Na semana passada, um usuário do X postou uma captura de tela supostamente mostrando duas novas frases adicionadas ao prompt do sistema do Claude Code: “Crie jogos originais, jogos de um gênero e jogos a partir dos próprios designs e recursos do usuário. Não crie uma recriação de um jogo existente específico, mesmo que seja nomeado ou chamado de original.”

Addy Osmani, da Anthropic, em resposta , não confirmou esse idioma específico, mas disse que a empresa atualizou o prompt no Claude Code no Opus 5.5:

Adicionamos duas frases ao aviso do Claude Code no Opus 5.5 para evitar recriar o jogo específico de outra pessoa, porque usar o Claude para infringir o IP é contra nossa política de uso.

Jogos originais, jogos de gênero e jogos criados a partir de seus próprios designs e recursos devem continuar funcionando.
