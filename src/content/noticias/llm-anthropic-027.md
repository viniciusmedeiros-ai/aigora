A Anthropic fornece este guia de migração para atualizar para 1.0, então solicitei o Fable 5 no Claude Code com:

Atualize para Anthropic&gt;=1 - leia https://raw.githubusercontent.com/anthropics/anthropic-sdk-python/refs/heads/main/MIGRATION.md e obtenha aprovação nos testes
